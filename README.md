# 🤖 YOLOv8 Object Detection App

An AI-powered Object Detection application built using **YOLOv8**, **Python**, **Streamlit**, and **OpenCV**. The application supports object detection on **images**, **videos**, and **live webcam streams** through an interactive web interface.

---

## 🚀 Features

- 📷 Image Object Detection
- 🎥 Video Object Detection
- 📹 Live Webcam Object Detection
- 🎯 Adjustable Confidence Threshold
- 📊 Detection Dashboard
- 📈 Object Count Analysis
- 🥧 Object Distribution Pie Chart
- 📄 CSV Detection Report Download
- 💾 Download Detection Image & Video
- ⚡ Powered by YOLOv8

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/nithin095/YOLO-Object-Detection-App.git
cd YOLO-Object-Detection-App
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
